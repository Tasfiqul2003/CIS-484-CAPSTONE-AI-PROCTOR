The real generated-audio codec check used a native spoken fixture connected only
to `AudioContext.createMediaStreamDestination`, real `MediaRecorder` WebM/Opus,
and production WAV conversion. It produced **27,944 WebM bytes → 119,084 WAV
bytes**, **3.72s**, with **zero** microphone/display calls or speaker connections;
headless Chrome used `--mute-audio`. It created no student session or forged
identity/recording gate. This evidence is distinct from the generated-canvas
WebRTC test and from real-device acceptance.
