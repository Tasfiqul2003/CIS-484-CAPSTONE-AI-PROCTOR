## Implemented contracts

Bounds are explicit; missing rubrics, weights, unsupported types, duplicate names and nonfinite bounds block new grading before model calls/inserts. Suggested defaults require an explicit save. - New attempts copy their template rubric in the same SQL insert as their attempt. Additive `022_attempt_rubric_snapshot.sql` preserves NULL for historical snapshots. Unknown legacy attempts cannot receive newly invented grade rows. Existing grade rows and their explicit professor confirmation remain available with historical/unknown provenance.
- Follow-up decisions receive the approved root, frozen rubric, objectives, prior answers, approved material and remaining permission/restrictions. A bounded structured decision must identify missing evidence and the same root. Shortness/uncertainty cannot force a stock question. Official-bank exhaustion ends an assessed attempt after the targeted decision; generic model questions remain demo-only.
- Speech/FlashHead share current-question and saved-assistance delivery resolution. Student replacement text is forbidden. Assistance requires a successful operation for this session/interaction. Receipt issuance/verification and automatic versus reviewed transcript provenance stay in the backend. Old transcription is explicitly unsigned review-only, with bounded upload reads and current-state guards.
- `CYBROS_SPEECH_PROVIDER=avatar-service` selects authenticated internal HTTP adapters. Set `CYBROS_SPEECH_SERVICE_URL` and `CYBROS_SPEECH_SERVICE_TOKEN` server-side. Missing setup/readiness has a precise UI notice and preserves keyboard recovery. Windows system speech and minimal/unconfigured modes remain separate. The adapter uses protected `/service/speech/status`, `/service/speech/synthesize` (PCM WAV), and `/service/transcribe`. Its audio-only voice is the neutral pretrained voice, not professor voice cloning; the calm/clear labels use that same provider voice. - Additive `023_attempt_avatar_profile.sql` freezes the explicitly selected examiner identity for new attempts. Unknown/unselected attempts fail clearly; they never borrow a globally active professor. Renderer service requests name that identity. The full synchronous generation stream holds the same profile reservation used by activation/prerender; profile file writes also serialize. Cancellation closes the generator rather than leaving detached service TTS/render workers behind.
- Configuring `AVATAR_SERVICE_TOKEN` puts the separate avatar app in authenticated service mode, including its formerly public prototype/mutation/media routes. Standalone prototype mode is available without that token. Backend live/preview video uses short-lived name/profile/session-or-professor scoped media capabilities. Completed exam review uses authenticated retained assets instead. Capabilities expire after five minutes and cannot be used after their student attempt ends. Exact renderer MP4 bytes are saved before exposure, with size/hash/duration/type checks. Incomplete streams are not replayable as complete deliveries. Finished primary deliveries replay the same assets. WAV variants and MP4 segments have separate budgets. Retrieval and the existing retention inventory handle both canonical UUID extensions.
